## Logo

The launcher icon (`drawable/ic_dawn_*.xml`) is a dolphin silhouette traced
from https://pixabay.com/vectors/dolphin-jump-silhouette-black-310084/ ,
mirrored, rotated and set in front of a sun circle and a cloud deck.
